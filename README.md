📊 Retail Sales Performance & Profitability Analysis Dashboard

📌 Project Overview
This project is an interactive Power BI dashboard developed to analyze retail sales performance and profitability. It transforms raw retail sales data into meaningful business insights using KPIs, charts, and interactive slicers to support data-driven decision-making.

❗ Problem Statement
Retail businesses generate large volumes of sales data, making it difficult to manually identify sales trends, profitable regions, top-performing products, and valuable customers. This dashboard provides a centralized view of key business metrics to simplify analysis and improve decision-making.

🎯 Objectives
- Analyze overall retail sales performance.
- Monitor revenue, profit, and profit margin.
- Identify top-selling product categories and sub-categories.
- Compare sales across different regions.
- Analyze customer segments and top customers.
- Provide interactive filtering using Year, Region, and Category slicers.


📈 Dashboard KPIs
- 💰 Total Revenue
- 💵 Total Profit
- 📊 Profit Margin %
- 🛒 Total Orders
- 💳 Average Order Value
- 📦 Total Quantity Sold


📊 Dashboard Visualizations
- Revenue & Profit Trend
- Sales by Category
- Sales by Region
- Sales by Segment
- Top 10 Sub-Categories by Sales
- Top 10 Customers by Sales


🎛️ Interactive Filters
- Year
- Region
- Category

🛠️ Tools & Technologies
- Power BI
- Microsoft Excel
- SQL

📁 Dataset
Sample Superstore Dataset

💡 Key Insights
- Technology generated the highest sales.
- Consumer segment contributed the largest share of revenue.
- West region recorded the highest sales.
- Top 10 customers contributed significantly to overall sales.
- Interactive slicers allow users to analyze data by Year, Region, and Category.
